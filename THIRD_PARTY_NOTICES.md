# Third-party sources and assets

## Historical reading-interface reference

Early private prototypes studied [Nutlope/gloss](https://github.com/Nutlope/gloss), snapshot `54b13b8882d8a109132c5b2045acd6b45628563d`. Those prototypes included a closely adapted margin-placement function, copied CSS token/rule groups and the upstream paper-grain SVG. The upstream snapshot did not declare a distribution license.

The 0.12.1 publication preparation replaces the identified function with a cumulative-height constraint layout and replaces the identified reading-surface/mark/toolbar rules and texture with local implementations. It does not relicense the upstream source or claim permission from its author. Historical references are retained in this document rather than being presented as current bundled-code licenses.

The reader's Obsidian views, API/CLI integrations, document storage and quote anchors, native PDF integration, EPUB parser, book indexing, notebook handling and Chinese prompts remain in their existing native implementations. A shared feature, output schema, standard DOM operation or generic sorting expression is not treated by itself as evidence of source copying. The existing `gloss-reader` storage/view identifier is retained for compatibility; this is an independent Banana Reader community plugin, not an official Gloss product.

Qiaomu Reader was an interaction reference. A similar EPUB archive-path helper was also identified in a second comparison pass and replaced with a Node.js standard-path implementation. That local finding is not treated as proof that the whole EPUB parser derives from Qiaomu. No Qiaomu GPL component is bundled into this release. Obsidian's built-in PDF viewer and icon API remain host dependencies; the plugin does not bundle PDF.js, React, Next.js, Clerk or upstream web application services.

## Fonts

Newsreader and Schibsted Grotesk font files were obtained from the rendered reference page on 2026-10-15 and are embedded unchanged in plugin CSS under local CSS family aliases. These font projects independently license their binaries under the SIL Open Font License below. Their bytes are retained; replacing unlicensed application snippets does not require replacing these licensed fonts. They work offline and do not load from a third-party font CDN at runtime.

## Icons

Icons use Obsidian's built-in Lucide icon API, matching the icon family used upstream. Lucide is ISC licensed: https://github.com/lucide-icons/lucide/blob/main/LICENSE .

## Comparison article

The public-domain Schopenhauer article is a local verification fixture created from the upstream sample content and is not bundled into the plugin or uploaded as vault data. Its source is Project Gutenberg, The Art of Literature, translated by T. Bailey Saunders: https://www.gutenberg.org/ebooks/10714 .


## EPUB archive reader

EPUB archives are decoded locally with fflate 0.8.3. PDF pages use Obsidian's built-in PDF viewer without bundling or modifying PDF.js.
