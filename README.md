# 沉浸阅读 for Obsidian

在 Markdown、PDF、EPUB 旁边阅读、提问、划线和留下理解的桌面插件。版本 0.9.0（验收中）。

本版直接适配 Gloss 的阅读界面源码：字体、纸张纹理、页面网格、黑色选文浮层、四色高亮、朱红下划线、页边卡片和段落缩略轨道。React / Next.js 的界面机制译为 Obsidian ItemView 与原生 DOM，模型服务沿用本插件的 Codex CLI / 兼容 API 多种接入。

## 使用

- 文件默认照常用 Obsidian 打开。点击左侧 `进入沉浸阅读` 图标，或运行命令 `沉浸阅读: 进入沉浸阅读`，才进入沉浸模式；文件右键也可进入。
- 选中正文：提问、全部已配置指令、写批注、复制、管理指令；标记工具放在末尾。支持直线、波浪线、荧光笔与黄/绿/蓝/粉四种颜色。输入问题或批注时，原文选区持续高亮。选中不会自动发送。
- 底部提问栏默认收起，点击工具栏气泡按钮或按 / 打开；按 Esc 或关闭按钮收起，草稿保留。提问栏切换“选文 / 全文”，输入问题，按 Enter 发送、Shift+Enter 换行。也可在选文浮层发问。回答显示在对应段落旁，可展开、停止、继续追问或复制。窄分栏通过笔记本查看回答。
- 回答中的 `[¶n]` 返回对应原文。每条对话保留开始时的上下文与引用锚点；原文变化后用摘录重新定位，无法可靠匹配会明确提示。
- Esc 或工具栏“返回文档”退出，回到原来的普通文档；/ 打开提问（保留当前选文）；可为“显示 / 收起提问框”命令自定义快捷键。工具栏可调整纸张、字体、字号、行距，或打开目录；左侧段落缩略轨道支持点击与拖动。沉浸模式仍可选文和与 Agent 交互。
- “导出笔记”会在 `收集箱/` 新建 Markdown，含摘录、批注、完整对话与原文回跳链接。不会覆盖旧笔记。

## PDF 与 EPUB

- **PDF**：使用 Obsidian 自带 PDF 阅读器显示原版页面，保留字体、图片、表格和版式，不转换成 Markdown。沿用原生翻页、缩放、目录与搜索；选文后可提问、划线或批注。模型上下文是当前页的文字层，回答与标记保存 PDF 页码，笔记本和导出保留页码及回跳。
- PDF 书页不会跟随阅读字体/字号重排。扫描页仍可原版阅读，但本版不含 OCR，缺少文字层时不能选文问答或做文字标记；加密 PDF 由原生阅读器处理。当前不提供整本 PDF 总结或跨页选择。
- **EPUB**：按书内 spine 顺序重排章节，显示标题、作者、正文、代码块和本地栅格插图；使用现有主题、字体、章节目录、问答和笔记本。正文不会执行书内脚本或加载远程图片。保留章节来源供模型引用。
- EPUB 限 40 MB、解压后 64 MB、单个资源 12 MB、单章 4 MB、600 个章节文件及 200 万字符；超限明确提示。暂不支持 DRM、纯图片书、音视频、SVG 插画或原书 CSS/固定版式复原。
- PDF 默认仍以原生 Obsidian 打开；主动点击插件进入沉浸阅读。没有其他 EPUB 阅读器注册时，EPUB 先打开一个阅读入口，再点击进入。

## Agent

在“模型服务”中点击“添加服务”，选择 Codex、Claude、Pi 或自定义 API；同一类型可添加多个独立命名的服务。保存连接后获取模型，勾选并添加；也能手动输入模型 ID。每个服务分别保存地址、协议、模型列表和密钥引用。

- **Codex**：读取本机 Codex 模型缓存；使用本机登录，独立临时目录与只读模式。
- **Claude**：提供 sonnet / opus / haiku 常用别名，可手动填写完整 ID；别名列表不代表账户一定有权限。保留登录，关闭工具、自定义配置和会话持久化。
- **Pi**：通过本机 Pi RPC 获取已配置且可用的模型，模型 ID 含 provider 前缀，避免不同提供商同名模型冲突。问答使用 JSON 流；关闭工具、扩展、技能、Prompt 模板、上下文文件和会话保存，复用本机 Pi 的认证。
- **自定义 API**：支持下表四种协议，可添加多个同协议不同地址的服务。Key 存在 Obsidian 密钥存储中，插件数据只保存服务 ID；不会写入源码或插件 data.json。最低 Obsidian 版本为 1.11.4。获取模型只访问当前服务的模型列表接口。

在“用途分配”分别选择 **默认问答、翻译、总结** 的服务与模型；翻译和总结未单独分配时跟随问答模型。每条自定义选文指令也可在编辑器中单独选模型。阅读中临时切换影响当前问答及未单独分配的指令；已分配的翻译、总结保持各自模型。全文总结走总结用途，内置翻译走翻译用途。每条回答记录实际服务名称与模型。

旧版配置按原服务与协议迁移，批注与笔记不变。删除服务或模型时清除相关用途分配，不自动替用户选择另一默认服务；原有问答保留。新安装从空服务列表开始。

| 协议 | 基础地址示例 | 请求路径 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1` | `/chat/completions` |
| OpenAI Responses | `https://api.openai.com/v1` | `/responses` |
| Anthropic Messages | `https://api.anthropic.com/v1` | `/messages` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | `/models/{model}:streamGenerateContent?alt=sse` |

## 选文指令

- “选文指令”最多8条，内置与自定义合计。默认提供解释、释义、简化、反例、翻译。
- 每条均可编辑名称与 Prompt、调整顺序、删除。内置指令编辑器可以恢复默认内容，删掉的内置指令也能单独恢复。
- 名称最多16字符，Prompt 最多8,000字符。可使用 `{{selection}}`（选文）与 `{{title}}`（文档名）；变量按文字替换，不执行代码。上下文与引用仍由阅读器提供。
- 工具条同时显示全部已配置指令（最多 8 条），窄窗口自动换行，不折叠。“提问”、标记、文字批注、复制属于固定工具，不占8条指令名额。
- 原文、批注与问答记录不因编辑指令而改变。

设置中获取模型不会发送笔记。点击发送才调用模型；正文会由该模型服务处理。本地 CLI 运行不代表模型离线。此版是阅读问答伴侣，不提供让 Agent 修改库文件或执行任意任务的入口。

## 数据和边界

文档不被修改。批注、对话、上下文快照、草稿与阅读进度保存在 `<vault>/.obsidian/plugins/gloss-reader/data.json`。移除高亮是软移除，可恢复。文件/文件夹重命名时保留批注；目标路径已有记录时保留两份而不覆盖。插件没有独立云同步；若用户同步 `.obsidian`，数据也可能由同步工具传走。

`日记/`、`60_工作库/`、`20_投资库/`、`A1_交易数据/` 不进入阅读器或 AI 上下文。其他笔记的嵌入不会自动展开给模型，正文中的本地图片正常显示。仅处理用户明确打开的文档，不递归读取整个库。

目前支持 Markdown、原版 PDF 与文字型 EPUB。网页导入、书架、联网搜索、朗读、移动端未实现。复杂第三方 Markdown 渲染器动态产生的内容不保证可选文定位。超出上下文字符上限会提示，不静默截断。

## 构建和安装

```sh
npm install
npm test
npm run build
```

将 `main.js`、`styles.css`、`manifest.json` 和 `THIRD_PARTY_NOTICES.md` 放进 `<vault>/.obsidian/plugins/gloss-reader/`，在 Obsidian 第三方插件里启用。工程源码留在项目库，不放进笔记库。`main.js` 和 `node_modules` 不进入 Git。

## 来源和适配范围

- [Nutlope/gloss](https://github.com/Nutlope/gloss)：直接适配阅读区 CSS、选文浮层、分段标记、页边避让和缩略轨道的布局与交互；真实 Newsreader / Schibsted 字体嵌入本地 CSS，可离线显示。源文件对应和字体许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- [Qiaomu Reader](https://github.com/joeseesun/qiaomu-reader)：参考主动选文提问、独立阅读上下文和伴读专注模式，未拷贝其源码、字体或示例书。

本插件不是上述项目的官方版本。Gloss 原版的账户、云端书架、网页导入和 Together 专用服务未移入。Obsidian 中使用中文操作文案和本地文档选择；中文正文使用系统衬线回退字体。
